# Venda-de-Carros
Site sobre uma venda de carros feito no meio de 2023


## Atualização desta versão
- Catálogo inicial ampliado de 5 para 8 modelos, fechando a grade em 4 + 4 no desktop.
- Fabricantes ampliados de 5 para 8 marcas, também em grade 4 + 4.
- Adicionados Chevrolet, Volkswagen e Nissan e os modelos Onix, T-Cross e Kicks.
- As novas imagens foram incluídas localmente em SVG para não depender de links externos.
